# Salary-Prediction-Based-on-Experience-using-Machine-learning-Project

## 📌 Project Overview

This project predicts the salary of an individual based on their years of experience using Machine Learning. It demonstrates how regression models can be used to understand and forecast real-world numerical data.

---

## 🎯 Objective

* Build a regression model to predict salary
* Analyze the relationship between experience and salary
* Visualize data trends and model performance

---

## 📊 Dataset

The dataset contains:

* **Years of Experience**
* **Salary**

This is a simple and commonly used dataset for learning regression concepts.

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

---

## ⚙️ Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Splitting Data (Train/Test)
5. Model Training
6. Model Evaluation
7. Prediction

---

## 🤖 Machine Learning Model

* Linear Regression

---

## 📈 Model Performance

* The model shows a strong linear relationship between experience and salary
* Accuracy is evaluated using metrics like R² score

---

## 🔮 Prediction

The model predicts salary based on input:

* Example:

  * Input: 5 years experience
  * Output: Predicted salary value

---

## 🚀 How to Run the Project

1. Open the notebook in Google Colab
2. Run all cells step-by-step
3. Enter years of experience to get salary prediction
